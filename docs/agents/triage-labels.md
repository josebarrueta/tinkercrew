# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repository's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                 |
| -------------------------- | -------------------- | --------------------------------------- |
| `needs-triage`             | `inbox`              | New work awaiting evaluation            |
| `needs-info`               | `blocked`            | Missing information or another blocker  |
| `ready-for-agent`          | `agent-ready`        | Fully specified for autonomous work     |
| `ready-for-human`          | `owner-review`       | Requires the owner's decision or action |
| `wontfix`                  | `not-planned`        | Will not currently be actioned          |

When a skill mentions a role, use the corresponding label string from this table.
